# nudo-web

Landing de **Nudo** — webs para bares y restaurantes · [nudodesign.es](https://nudodesign.es)

## Qué hay aquí

- `index.html` — la web entera en un solo archivo (fotos, CSS y JS dentro). No necesita build.
- `CNAME` — el dominio para GitHub Pages. No borrar.
- `nudo-og.png` — la imagen que sale al compartir el enlace (WhatsApp, redes). 1200 × 630.

## Cómo actualizarla

1. Add file → Upload files
2. Arrastrar el `index.html` nuevo (sobrescribe el anterior)
3. Commit changes

En un minuto está publicado.
